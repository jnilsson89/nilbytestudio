Identity proposal

Nilbyte Studio

An N built from two solid stems and eight bits — one byte — falling across the diagonal.

The idea

Nil holds the shape, the byte carries the data

The two stems are fixed and quiet. The diagonal is the part that moves: eight equal squares, evenly stepped, reading top-left to bottom-right the way a byte is written. It stays an N at a glance and rewards a second look.

Geometry is on a 100-unit grid, so every element lands on a clean number and scales without drift.

Variants

Four versions cover every placement

PRIMARY / TWO-COLOR
REVERSED / ON INK
MONO / ONE INK
APP ICON TILE

The mono version is the real test: the gaps between the bits do the work, so the mark survives one-color print, embroidery, and a black-and-white invoice header.

Lockup

Mark plus name

Type is Inter Tight — semibold for the name, a small letterspaced caps line for the descriptor. Keep clear space of one stem width on every side.

Rules

Keep it boring

  • Don't re-space the bits or change their count. Eight is the point.
  • Don't add a shadow, outline, or bevel to the mark.
  • Don't place the two-color version on a mid-tone background — use reversed or mono.
  • Do use the tile version for store listings and the bare mark everywhere else.
